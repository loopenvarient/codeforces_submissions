# Codeforces Submissions

This repository contains Python solutions to beginner-friendly Codeforces problems.

## Structure

- Each file is named using the format: `<problem_id><letter>_<problem_title>.py`
- Example: `112A_Petya_and_Strings.py`

## Notes

- Solutions are standalone scripts intended for Codeforces input/output format.
- Most files read from standard input and print the answer to standard output.
